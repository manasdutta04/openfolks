# Job Search

Scout, Tailor, Tracker, Coach, and Generalist — five folks plus a shared Job Search channel.

- **Scout** finds and ranks postings through portal CLIs.
- **Tailor** evaluates fit and drafts CVs and cover letters.
- **Tracker** logs applications, outcomes, and follow-ups.
- **Coach** preps interviews and LinkedIn drafts.
- **Generalist** handles ad-hoc work and coordinates the crew.

Install from **Marketplace → Job Search**. Point the crew at a project folder so everyone shares the same workspace.
