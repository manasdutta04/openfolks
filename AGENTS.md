# OpenFolks agent notes

Before claiming a harness or conversation change works, follow
[`docs/verifying.md`](docs/verifying.md). Launch an isolated fixture.
Never mutate the user's live Desk or data.
Use `pnpm control:folks` for those commands.

- **`apps/harness`** — local API, engines, MCP, persistence
- **`apps/desk`** — React Desk (conversations, settings, computer panel, Marketplace)
- **`apps/shell`** — Electron desktop shell
- **`docs/`** — short contributor notes

A more specific `AGENTS.md` in a subdirectory wins there.
