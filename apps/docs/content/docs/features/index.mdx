OpenFolks is a workplace for folks you hire. The harness turns each engine into one event stream so the Desk can treat them consistently while keeping their native strengths.

## Folks and conversations

- A folk per role, model, voice, and working folder
- Streaming replies with live tool activity
- Several tasks per folk, with searchable history
- Edit, branch, rewind, pin, reply, export
- Rooms for shared briefs and folk-to-folk handoffs
- Queueing and steering while a folk is already working
- Per-task token and cost visibility
- Readable, editable memory

## Computers and tools

- Local computer control with explicit opt-in on supported hosts; Ubuntu currently fails closed under an input-safety hold
- Isolated Local VM desktops through Docker or Podman
- Hosted Box cloud computers
- A self-hosted Linux VPS over Docker's SSH transport
- Live previews and in-app takeover where the backend supports it
- Connected apps through Composio, including several labeled accounts per toolkit

## Routines

- One-time and weekday runs
- Webhook-triggered work with dedicated secret endpoints
- Fresh task context and durable run receipts
- Notifications when something needs you

## Voice

- Spoken replies and per-folk ElevenLabs voices
- Native macOS dictation and half-duplex call mode

## Desktop

- macOS, Windows, and Ubuntu packages
- Themes and accessible contrast
- Sidebar sections, compact headers, pinned messages, spoilers, image attachments
- Automatic updates on macOS and Windows

<Callout type="info" title="Platform differences are real">
  macOS has the broadest native integration. Ubuntu chat, preview, Cloud, and Local VM work; host control is temporarily off. Windows installers are not signed yet.
</Callout>
