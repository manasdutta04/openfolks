## Images

Paste a screenshot into the composer or attach a file from disk. Add a short instruction: the highlighted UI, an error, a layout mismatch, or the whole frame.

## Search

Sidebar search looks through folk names and conversation text. Distinctive project names, issue numbers, or exact error fragments narrow results quickly.

## Message actions

- **Pin** decisions you want to keep in view.
- **Copy** a reply without selecting the bubble.
- **Reply** to quote a message in the next brief.
- **Retry** after a transient engine or connection failure.
- **Read aloud** when voice is configured.

<Callout type="info" title="Screenshots can leak secrets">
  Crop tokens, addresses, private repo names, and customer data before an image goes to a cloud-backed model.
</Callout>
