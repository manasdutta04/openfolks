This page lists published releases of the OpenFolks desktop app. Changes on `main` that have not been released are not listed.

## 1.0.4 — October 12, 2026

- Folks keep their own colour and shape in team rooms. The "Thinking" indicator, the small avatar beside each sender's name, and the "Messaged" chips used a default mascot before, so a blue folk could appear green.

[Release notes](https://github.com/manasdutta04/openfolks/releases/tag/v1.0.4)

## 1.0.3 — October 12, 2026

- Conversations between two folks are now read-only for you. The server refuses messages and reactions in them, and the message box is replaced by a note with buttons that open each folk's own chat.
- Folk-to-folk conversations no longer have an entry in the sidebar. Open one from the "Messaged" chip in a folk's chat, or from the Desk map.

[Release notes](https://github.com/manasdutta04/openfolks/releases/tag/v1.0.3)

## 1.0.2 — October 10, 2026

- Fixed the Windows taskbar showing a blank window icon instead of the OpenFolks icon.

[Release notes](https://github.com/manasdutta04/openfolks/releases/tag/v1.0.2)

## 1.0.1 — October 10, 2026

- The Windows icon file now ships next to the app instead of inside the app bundle, so Windows can read it.
- Installer build checks now fail if the icon is missing.

[Release notes](https://github.com/manasdutta04/openfolks/releases/tag/v1.0.1)

## 1.0.0 — October 10, 2026

The first public release of OpenFolks.

- Create folks, each with its own model, instructions, working folder, memory, tools and computer.
- Tasks, rooms and handoffs between folks, with approval cards for risky actions and a Backstage view of each turn.
- Computers: this computer (opt-in), an isolated Local VM, hosted cloud computers, or your own server.
- Routines and webhooks, connected apps, and ready-made crews from the Marketplace.
- Installers for Windows 10 and 11 (x64), macOS (Apple silicon and Intel) and Ubuntu 24.04 (x64, `.deb` and AppImage). The installers are not signed with an Apple or Microsoft certificate; each release publishes `SHA256SUMS.txt`.
- Released under the MIT License.

[Release notes](https://github.com/manasdutta04/openfolks/releases/tag/v1.0.0)
