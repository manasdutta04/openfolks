This page tracks published desktop builds. Changes on `main` after a release are not listed as shipped until a new build is out.

## 0.1.32 — August 23, 2026

- OpenCode now reads the installed CLI's live Zen, Go, third-party, and local provider inventory instead of a Go-only catalog.
- Existing OpenCode logins and anonymous free models work without duplicate setup.

[Full 0.1.32 notes](http://github.com/manasdutta04/openfolks/releases/tag/v0.1.32)

## 0.1.29 — August 23, 2026

- Stopped OpenCode Go's live cloud models from appearing as local models and skipping sign-in.
- Added direct latest-build downloads for Apple silicon, Intel Mac, Windows, and Ubuntu.

[Full 0.1.29 notes](http://github.com/manasdutta04/openfolks/releases/tag/v0.1.29)

## 0.1.27 — August 20, 2026

- Added the Cursor Agent CLI engine with ACP model discovery.
- Added pasted screenshot attachments and labeled sidebar sections.
- Repaired the macOS update restart path and made browser join links resilient to popup blocking.
- Added approval audit records, credential hardening, pinned messages, more reactions, room timeouts, and temporary computer takeover.
- Licensed the project under MIT.

[Full 0.1.27 notes](http://github.com/manasdutta04/openfolks/releases/tag/v0.1.27)

## 0.1.25 — August 20, 2026

- Signed and notarized Intel macOS build.
- First Ubuntu 24.04 x64 `.deb` and AppImage beta packages.
- Four themes, spoiler text, safer additive team import, and several approval and model-routing fixes.

[Full 0.1.25 notes](http://github.com/manasdutta04/openfolks/releases/tag/v0.1.25)

## 0.1.24 — August 19, 2026

- Readable folk memory, working folders, cost tracking, message search, and a raw event inspector.
- Bring-your-own VPS computers and major harness reliability fixes.

[Full 0.1.24 notes](http://github.com/manasdutta04/openfolks/releases/tag/v0.1.24)

## 0.1.23 — August 17, 2026

- Fixed the Composio OAuth completion flow.
- Clearer updater states, a new app icon, and correct delegated-turn terminal status.

[Full 0.1.23 notes](http://github.com/manasdutta04/openfolks/releases/tag/v0.1.23)

## 0.1.22 — August 17, 2026

- One validated Composio project key instead of a two-key connector setup.
- Connector lifecycle moved to Composio Sessions with real grant revocation on disconnect.

[Full 0.1.22 notes](http://github.com/manasdutta04/openfolks/releases/tag/v0.1.22)
