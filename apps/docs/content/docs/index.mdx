## How the Desk is organized

| Piece | What it holds | Where you set it |
|---|---|---|
| **Folk** | Identity, conversation, memory, defaults | Folk profile |
| **Engine** | The reasoning loop and tools | Model picker and Settings |
| **Working folder** | Project context and a safe place to write | Folk profile |
| **Connected apps** | Services you authorized | Connections |
| **Computer** | Visual control of a desktop | Computer panel |
| **Routines** | Work that runs later, on a weekday, or from a webhook | Automations |
