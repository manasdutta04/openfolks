## Install an engine

The Desk launches agent CLIs you already have. Claude and Codex are the usual first pair.

1. Install the CLI from its provider.
2. Run it once in a terminal and finish sign-in.
3. Restart OpenFolks.
4. Open the model picker. Ready engines appear; missing ones say what to do next.

See [Engines](../providers/index.mdx) for the full list and path overrides.

## Build from source

Need Node.js 24+, pnpm 10.33.0, and at least one signed-in engine CLI.

```bash
git clone http://github.com/manasdutta04/openfolks.git
cd openfolks
corepack enable
pnpm install --frozen-lockfile
```

Three terminals:

```bash
pnpm dev:server
pnpm dev
pnpm dev:desktop
```

## Where data lives

Application data is `~/.openfolks`. Electron window and browser data use the normal per-platform app-data directory. Override the data root with `OPENFOLKS_DATA_DIR`.
