OpenFolks supports several labeled accounts for the same toolkit — two Gmail inboxes, several Slack workspaces, or separate personal and work services.

## Add another account

1. Open **Connections**.
2. Find an already connected toolkit.
3. Choose **Add account**.
4. Enter a unique label such as `work`, `personal`, or the workspace name.
5. Complete authorization in your browser.

When more than one account could run a tool, the session requires an explicit choice. A new authorization does not silently become the default for the old one.

## Disconnect one

Each account appears separately with its alias and status. Disconnect removes only the chosen account.

OpenFolks caps each toolkit at five usable accounts. If a provider or Composio project policy blocks another authorization, use a separate OpenFolks install rather than reauthorizing over a working account.
