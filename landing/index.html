Work with many folks at once

Hire a folk, give it a job, then add another when the work grows — one on a project, one on outreach, one on systems. They work in parallel and keep going while you do something else.

  • One folk per role, model, voice and working folder
  • Rooms for shared briefs and folk-to-folk handoffs
  • Per-task token and cost visibility

  • Connected apps through Composio and your own MCP tools

First launch on an unsigned build

OpenFolks is free and open source, so the installers are not signed with a paid Apple or Microsoft certificate. Your OS will warn you once. If you like, check the file against SHA256SUMS.txt on the release, then:

Windows

SmartScreen → More info → Run anyway.

macOS

Drag to Applications, then run this once — or right-click the app → Open → Open.

xattr -cr /Applications/OpenFolks.app
Linux

The .deb is the easiest route:

sudo apt install ./OpenFolks-amd64.deb

FAQs

How is OpenFolks different from an AI chat assistant?

Folks have a role, memory and a computer to work on. They use tools, run in parallel and can be put on routines — so you hand off work instead of copy-pasting prompts.

Is it really free?

Yes. OpenFolks is MIT-licensed. You bring the engines or API access you already have; any usage is billed by those providers, not by OpenFolks.

Where does my data live?

On your machine, in ~/.openfolks (override with OPENFOLKS_DATA_DIR). Content only leaves when you send it through an engine or a connected app.

Can a folk control my computer?

Only if you opt in, on supported hosts. You can also run folks in an isolated Local VM or a cloud desktop instead.

Why does my OS warn me when I install it?

The installers are unsigned — a trade-off of shipping free open-source software without paid signing certificates. The steps above clear it in a few seconds.

Which platforms are supported?

Windows 10/11 (x64), macOS (Apple silicon and Intel) and Ubuntu 24.04 (x64). There is no mobile app.
