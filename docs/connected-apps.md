# Connected apps

Connected apps give folks authenticated tools (mail, calendar, CRM, and the rest) through the Composio integration.

- Desktop: **Connections**, plus per-folk Connected apps toggles
- Optional hosted broker: `cloudflare/composio-broker`
- Self-hosting a broker is advanced. Most installs use the managed or key-based flow in Settings

Do not commit API keys. Scrub secrets from logs the same way the harness redacts other credentials.
